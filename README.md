# Hello World

Projeto inicial desenvolvido para a disciplina de Cultura e Práticas DevOps.

## Sobre o projeto

Este projeto tem como objetivo praticar os conceitos iniciais de Git e GitHub utilizando uma página HTML simples.

## Arquivos

- `HelloWorld.html` — página contendo a mensagem Hello World.
- `README.md` — documentação do projeto.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `HelloWorld.html` em qualquer navegador.
